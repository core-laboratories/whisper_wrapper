WhisperLiveSession

WhisperLiveSession class

A running live transcription session.

Obtain one from WhisperController.transcribeLive or startWhisperLiveSession. Listen to partials for progressively refined transcripts while audio is being fed, and call stop to get the final text and release the native context.
